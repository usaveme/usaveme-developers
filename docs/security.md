# Security and child protection

## Wallet and token safety

- Never request a seed phrase, private key, or wallet recovery code.
- Treat token addresses, pool addresses, and transaction IDs as untrusted until verified.
- Keep signing separate from read-only blockchain queries.
- Do not promise returns, guaranteed liquidity, or risk-free trading.

## Platform security

- Use HTTPS, scoped access, MFA for administrators, and audit logging.
- Validate and sanitize all input; escape output according to context.
- Use server-side authorization for every protected operation.
- Protect API secrets outside public repositories and web roots.
- Rotate compromised credentials immediately.

## Child and family privacy

- Do not publish children's identifying information on chain.
- Minimize collection and retention of sensitive data.
- Verify organizations and enforce guardian consent where appropriate.
- Require human review and abuse-reporting mechanisms for public postings.
- Separate public project summaries from restricted beneficiary records.

## Reporting

Do not post vulnerabilities, keys, or sensitive personal data in public GitHub issues. Contact the project through its official website for a private reporting channel until a dedicated security address is published.
