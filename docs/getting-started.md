# Getting started

Welcome to the USAVEME developer ecosystem.

## Explore

1. Read the [token integration guide](token-integration.md).
2. Verify any token addresses through official project channels and on-chain explorers.
3. Read the [security guidance](security.md) before integrating wallets or handling personal data.
4. Follow the [API roadmap](api-roadmap.md) for planned integrations; do not treat roadmap features as available endpoints.

## Development principles

- Build with least privilege and explicit user consent.
- Keep child and family information private; never place identifying personal records on a public blockchain.
- Separate token-related activity from direct child sponsorship and payments.
- Do not claim guaranteed returns, liquidity, price appreciation, or exchange listings.
